# workshops

Набор примеров общего репозитория **Granio — Гранио**.

Исходник: [https://github.com/fyne-io/workshops](https://github.com/fyne-io/workshops).
Путь в общем модуле: `workshops`. История исходного набора сохранена.

Запуск из этого каталога: `см. корневой README.md`. Используются корневой `go.mod` и общие зависимости.
Для работы внутри внешнего workspace задайте `GOWORK=off`.

Первоначальные материалы сохранены в `UPSTREAM.md`, если они были в исходнике.
Коммиты и сведения о лицензиях: [SOURCES.json](../SOURCES.json).
