# Flatpak

Рецепт использует корневой Go-модуль и общие зависимости всех примеров.
Из корня репозитория:

```sh
make -C packaging/flatpak build
make -C packaging/flatpak install
make -C packaging/flatpak run
```

Перед сборкой создаётся общий `vendor/` в корне. Установленный SDK должен
содержать Go 1.27.1+. Включены Wayland и `fallback-x11`.

Исходная вложенная копия `vendor` сохранена вместе с материалами примера;
актуальный автономный набор формируется командой `go mod vendor` в корне.
Установка Flatpak требует отдельной проверки на целевой Linux-системе.
