# WebAssembly

Браузерная версия собирается из `demo/` общего репозитория и общего `go.mod`.
Нужны Go 1.27.1+, Git, tar и POSIX shell. Сценарий собирает выбранный коммит
в собственном временном каталоге и сохраняет результат в `site/`.

```sh
./packaging/web/update.sh            # текущий коммит
./packaging/web/update.sh dev/granio # выбранная ветка
python3 -m http.server 8080 --directory packaging/web/site
```

Упаковщик закреплён на опубликованной версии. Рядом с результатом записываются
коммит источников и версия инструмента в `SOURCE.json`. Развёртывание сайта
выполняется отдельно. `UPSTREAM_SOURCE.json` описывает прежний готовый артефакт.
